Margin vs Padding

margin = 요소 바깥 여백  |  padding = 요소 안쪽 여백

📦 Margin — 요소 바깥 여백 (파란 배경이 부모)

margin: 0

margin: 0

margin: 12px

margin: 12px

margin: 28px

margin: 28px

🔲 Padding — 요소 안쪽 여백 (박스 자체가 커짐)

padding 최소

padding: 4px 12px

padding 중간

padding: 14px 24px

padding 크게

padding: 28px 48px
