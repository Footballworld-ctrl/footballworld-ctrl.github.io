CSS Position

static · relative · absolute · fixed · sticky — 5가지 배치 방식 비교

1. static 기본값

모든 요소의 기본값. 문서 흐름(normal flow)에 따라 순서대로 배치됩니다.
top / right / bottom / left 속성이 무시됩니다.

첫 번째 박스 (static)
두 번째 박스 (static)
세 번째 박스 (static)

2. relative 상대 배치

원래 자기 자리를 기준으로 top/left/right/bottom만큼 이동합니다.
원래 공간은 그대로 유지되어, 주변 요소 레이아웃에 영향을 주지 않습니다.

원래 위치 (static)
relative → top:16px, left:24px 이동

3. absolute 절대 배치

가장 가까운 position이 static이 아닌 조상 요소를 기준으로 배치됩니다.
문서 흐름에서 완전히 빠져나와 다른 요소와 겹칠 수 있습니다.

position: relative (부모)
top-left
center
bottom-right

4. fixed 고정 배치

뷰포트(브라우저 창)를 기준으로 고정됩니다.
스크롤해도 항상 같은 위치에 머뭅니다. 우측 하단의 빨간 버튼이 예시입니다.

➡ 우측 하단의 📌 Fixed 버튼을 확인하세요.
페이지를 스크롤해도 항상 같은 자리에 고정됩니다.
내비게이션 바, 채팅 버튼, 쿠키 알림 등에 사용됩니다.

5. sticky 스티키 배치

평소에는 relative처럼 흐름에 있다가, 스크롤이 지정 위치에 닿으면 fixed처럼 고정됩니다.
